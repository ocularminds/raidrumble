# Original sound cues

RaidRumble synthesizes its short keyword, gate, weak-point and victory cues in
`apps/overlay/src/sound.ts`. These are original sine/triangle wave patterns, with
no recordings, samples or music from third parties. The generated waveforms are
dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Sound is off by default. The host can enable it in the dashboard. Browser previews
may need one click in the overlay to allow audio; OBS Browser Sources support the
same audio output. Muting stops active cues immediately. Reduced motion is a
separate preference.
